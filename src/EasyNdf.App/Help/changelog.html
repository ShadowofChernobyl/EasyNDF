What changed in each version, newest first.

1.1.2

Changed

  • What's New after an update lists every version since the one you had, not only the newest.

1.1.1

Fixed

  • Updates: EasyNDF 1.0.2 and 1.1.0 never looked for a new version. This version does again. If you are on 1.0.2 or 1.1.0, install this one by hand from GitHub.

Added

  • Settings > Data: Check Now looks for a new version at once.

1.1.0

Fixed

  • Armory: every mod that is on shows, whatever the Files tab lists.
  • Armory: a division card draws a new unit's own picture, and a battlegroup card's veterancy chooser fits its card.
  • Armory: typing in the weapons' Find no longer stalls, and the Weapons sub-tab no longer opens on an empty Compare.
  • Armory: long damage names are no longer cut short in the Swap popup.
  • Mods: a rule made from the Armory keeps its switch on when clicked.
  • Mods: a Lookup rule's Other File lists only the files on the Files tab.
  • Mods: text boxes of several lines start their text at the top, and the sideways scrollbar no longer covers it.
  • Mods: a deleted mod no longer leaves an empty folder behind.
  • File Editor: changing the text size keeps the top line in place.
  • File Editor: Show in File Editor finds its descriptor every time.
  • Export: one export is one step to undo.
  • Errors in work that finishes by itself are written to Errors.txt.
  • Languages: labels that were cut short, texts in stray quotation marks, and Armory labels that stayed in the old language after a switch.
  • Russian: one word for a unit and one for a division.
  • File Editor: script templates written with a meta block, as in Bricks.ndf, no longer show an error.
  • Rule popup: a Value box's last line no longer shows through its sideways scrollbar.
  • Armory: the weapon table's headings follow a change of language, and the Source box shows its choice at the left.

Changed

  • Files: choosing a Source lists all its files. A setting, on by default.
  • Files: two installs of the same game are told apart by their folder in the Source list.
  • Mods: rule sets are listed in the order they run. Ctrl+Up and Ctrl+Down move them, and groups of them.
  • Mods: an open rule holds back only its own window. The app's other windows go on working.
  • Divisions: a type's card slots stay on one line that scrolls, and Hide Slots hides them.
  • New Unit: finding a base unit is quick, missing files are named before the popup opens, and closing asks before dropping what you entered.
  • Find shows its count beside the box.
  • Usage bar: Memory is coloured by its share of the PC's memory.
  • Start-up: a small form with the version and a loading bar. Large mods load faster.
  • File and folder dialogs open in the middle of the screen the app is on.
  • Help says "popup" for the app's popups.

Moved

  • Mods menu: Export Mod and Import Mod are submenus, each with file and clipboard.

Added

  • Your own 3D models for units: a 3D Model step in New Unit, and Change 3D Model in the Armory.
  • Armory: WARNO's tabs can be edited, moved, added and removed from a tab's right-click menu.
  • Armory: Move to Tab on a unit's menu, with four spare tabs.
  • Armory: Mod Being Edited, under the Source, chooses the mod your changes are saved in.
  • Tabs in their own windows: right-click a tab, Open in New Window.
  • Game Update Check: Export asks to update a game mod folder made for an older game version first.
  • Variables: a Scope (This Rule Set, This Mod or All Mods), and a variable as an action's target.
  • Configure Several: set up several rules, conditions or actions as one.
  • Lookup rules have Applies to, Table rules take conditions, and a condition can be marked Must be true.
  • After a run: a warning when units are in an Armory tab a division has no cost row for, or a deck has more packs than slots.
  • Export and File Editor: a deck number given twice is reported with both names.
  • File Editor: keys to save, open, close and reopen files, move, copy, delete and comment lines, go to a descriptor and back, fold a block and wrap lines.
  • Mouse Back and Forward buttons in Help, the File Editor and between tabs.
  • Mods: Copy Mod to Clipboard and Import Mod from Clipboard.
  • Help and tips explain what each of 2,273 types is for.
  • What's New shows once after each update.
  • Rule popup: the File Editor's file filter beside the Other File and Property Scan dropdowns.
  • File dropdowns: a typed letter goes to the first file that starts with it.
  • After an update that brings a newer WARNO Tactical Overhaul, EasyNDF asks whether to update yours. Settings > Data turns the question off and on.
  • About: a Discord button.

Updated

  • Help: every page brought up to date with the app, in all five languages.
  • WARNO Tactical Overhaul: the version that comes with the app, with plain names for its conditions and actions.

1.0.2

  • Tutorial: with the panes below the list, Details and the Descriptor Tree can be opened, and Skip Step goes on from there.
  • Tutorial: Skip Step is off on the steps the later chapters need, such as making the rule and running Preview.
  • Tutorial: the condition's and the action's own line is outlined to double-click.
  • French and German: the Escape key in the tutorial is drawn as a key.

1.0.1

  • The installer's progress bar looks like the app's own loading bar.
  • French: the search hint in Help's Documentation is corrected.

1.0.0

  • The first version of EasyNDF as a Windows desktop app. It does what the browser version does, and opens the mods made in it.
  • Your mods, settings and themes are kept in %LOCALAPPDATA%\EasyNDF.
